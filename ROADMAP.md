# RollScript Roadmap

This roadmap describes the current development direction of RollScript.

It is intentionally flexible and may change as the project evolves and community feedback is received.

## Current

* Core application architecture
* Label editor
* Block-based label design
* Text blocks
* Continuous-roll label support
* Printer selection
* Printer discovery
* Plugin architecture
* DYMO LabelPOINT 350 printer plugin
* Linux development and testing

## Next

* Image blocks
* QR-Code blocks
* Barcode blocks
* Additional printer plugins
* Improved label editing
* Better error handling and diagnostics
* Improved documentation

## Plugin Ecosystem

Longer-term goals include:

* Stable public plugin API
* Plugin developer documentation
* Community-developed plugins
* Additional printer plugins
* Additional feature plugins

## Future

Possible future areas include:

* Additional platforms
* Import and export functionality
* Improved project and label management
* Additional printing workflows

The exact order of these features is not fixed.

Community feedback and real-world usage will influence the development priorities.
